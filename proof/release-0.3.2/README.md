# SDK 0.3.2 real-stack proof

The actual packed SDK called an owned local API, Supabase database/Storage, Cloud Slice and Bambu engine, then the real output-processing worker admitted a queued job. Product source was unchanged at the commit in `identities.json`.

Selected plate 2 used all four PETG source filaments. Three live SDK job reads reported exactly one unmet requirement, Source Slot 3, with material/color, cause and its explicit AMS/slot hint. A normal mock-printer claim returned no job while that filament was absent. Adding only the fourth owned loadout and fresh telemetry allowed the same job to be claimed.

`transcript.jsonl` contains a sanitized projection of the actual API calls and results, with no credentials, signed URLs or private filesystem paths. `identities.json` records the source, SDK proof tarball, engine, runtime and input identities. The observed duration is not a benchmark.

All owned processes/containers stopped and locks were released. No production API, real printer, Host process, G-code dispatch or physical printing was used. Reject mode was not part of this real-stack run; the UI fixtures test those separate presentation paths. Post-publication registry test results are recorded separately.
